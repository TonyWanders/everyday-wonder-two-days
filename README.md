A program that writes one sentence about a small moment of everyday wonder
to `/output/entry.txt`, for the make.fun competition
[Everyday Wonder, Two Days to Find the Line](https://make.fun/bounty/u-pangg7-everyday-wonder-two-days-to-find-the-line-970432d3).

Run it with Python 3:

```
python3 main.py
```

It writes the sentence below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`) and prints it to stdout. No network,
no clock, no randomness. The sentence is 90 characters, inside the 1 to 200
gate.

## The sentence

```
My shadow reached the corner before I did and waited there, already tired of following me.
```
